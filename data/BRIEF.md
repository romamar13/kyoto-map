# Задача для исследователя: данные о местах Киото

Ты готовишь данные для личного PWA-приложения-карты Киото (путешественник из России, будет пользоваться на iPhone в поездке).
Для КАЖДОГО места из своего списка собери актуальные данные (2025–2026) и запиши JSON-массив в файл, указанный в задании.

Используй WebSearch/WebFetch для проверки часов работы, цен, способов оплаты и необходимости брони
(официальные сайты, japan-guide.com, kyoto.travel, Google). Не выдумывай — если не уверен, пиши осторожно ("уточнить на месте").
Координаты бери из Википедии: `curl -s "https://en.wikipedia.org/w/api.php?action=query&prop=coordinates&format=json&titles=TITLE"`
(или ja.wikipedia.org для малоизвестных мест). Координаты должны указывать на сам объект (главный вход/главный зал), не на центр города.

## Схема одного объекта (все тексты — на русском, кратко, без воды)
```json
{
  "id": 35,
  "name_ru": "Киёмидзу-дэра",
  "name_en": "Kiyomizu-dera Temple",
  "name_ja": "清水寺",
  "source": "map",                       // "map" для мест с карты, "extra" для дополнительных
  "unesco": true,
  "category": "temple",                  // temple | shrine | castle | garden | street | nature | museum | market | other
  "area": "Хигасияма",                   // район/местность по-русски
  "lat": 34.99485, "lng": 135.78504,
  "priority": 1,                          // 1 = must-see, 2 = стоит посетить, 3 = если есть время/интерес
  "short": "Деревянная терраса над склоном и вид на весь Киото",   // хук ≤ 80 символов
  "description": "3–5 предложений: что это, чем знаменито, что посмотреть внутри. Живо и по делу.",
  "hours": "06:00–18:00 (летом до 18:30, весной/осенью вечерние подсветки)",
  "open": "06:00", "close": "18:00",      // типичные часы для индикатора "открыто сейчас"; если доступно круглосуточно — "open": "00:00", "close": "24:00"; если неясно — null
  "closed": "Без выходных",               // выходные дни, если есть (например "Пн; 29.12–3.01")
  "duration": "1–1,5 ч",
  "ticket": {
    "price": "500 ¥ (дети 200 ¥)",        // или "Бесплатно"; если платные только отдельные части — укажи
    "payment": "Только наличные",         // способы: наличные / карты / IC (Suica/ICOCA) / QR — как есть на самом деле
    "booking": "Не нужна",                // или "Обязательно заранее: ссылка/как" / "Желательно в сезон"
    "note": "Важная деталь, если есть (например: вход в зал без обуви; фото внутри запрещено). Иначе пустая строка"
  },
  "crowd": {
    "level": 5,                            // 1 = почти пусто ... 5 = очень людно в пиковое время
    "best": "До 8:00 или после 17:00 в будни",
    "peak": "10:00–15:00, выходные, сезон сакуры и осенних клёнов"
  },
  "tip": "1–2 предложения: как лучше всего посетить. Конкретно: когда приехать, откуда зайти, что не пропустить, что купить/потрогать/попробовать.",
  "wiki_en": "Kiyomizu-dera",             // точный заголовок статьи en.wikipedia (или null)
  "wiki_ja": "清水寺",                    // точный заголовок статьи ja.wikipedia (или null)
  "website": "https://www.kiyomizudera.or.jp/en/"   // официальный сайт или null
}
```
Важно:
- Пиши для человека, а не энциклопедию: конкретика, что увидеть, лайфхаки.
- Указывай реальную ситуацию с оплатой (многие храмы — только наличные; Нидзё-дзё, Кацура и т.п. — свои правила).
- Места, где нужна предварительная запись (Сайхо-дзи/Кокэ-дэра, Кацура Рикю, Сюгакуин и т.д.) — обязательно укажи как бронировать.
- `id` и `source` бери из задания.
- Файл: валидный JSON (массив), без комментариев. Проверь `python3 -c "import json;json.load(open('FILE'))"`.
- Ответ в конце: коротко — сколько мест записано и какие места вызвали сомнения.
